# Make the AI Judge Feel Proud: A Family Scene

A tiny Python program that writes a one-or-two-line family scene to
`/output/entry.txt`. A mother comes home at 3 a.m. in her bus uniform; her son,
who once hid from that uniform, finally sees her sacrifice — and steps up,
with a wry warning about his reheating skills.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Requires only Python 3 (standard library only). The output is UTF-8 text of
1–280 characters.
